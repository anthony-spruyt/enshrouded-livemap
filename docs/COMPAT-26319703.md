# Local compatibility build: Steam 26319703 / SVN 1283531

This is a narrow patch on v1.7.0 (5e4afb2092d2fec42509655e871db475ef8d99cb),
not the newer unreleased upstream feature set. Upstream issue:
<https://github.com/oggii/enshrouded-livemap/issues/1>

## Executable evidence

Exact executable SHA256:
`4429653ac0cfa154bc08e138853caa5d8557f82129b7488031f40345816aa6dc`.
PE timestamp `1793351714`, image size `0x1dde000`.

The new fingerprint alone is insufficient. Three original signatures no longer
match. Compare the functions using PE unwind ranges and instruction-level
disassembly; do not infer compatibility merely from nearby addresses.

| chat post | 0x90b330 | 0x915170 | Original signature retained; announcements remain optional |

The player-manager function still accesses slots at +0x1e0 with stride0x148,
state+0xa and entity+0x18. The daytime fragment is instruction-equivalent after
normalizing relative branch/call targets. Mining now stores item EAX at
`[rsp+0x68]` and quantity EBP at `[rsp+0x6c]`, instead of the old EBP/R15D
pair. `MiningLayout` explicitly selects the register decoder by accepted build.
This avoids misinterpreting a quantity as an item ID.

Additional layout checks: the complete movement fragment and player knowledge
accessor are instruction-equivalent after normalizing relative targets (new
accessor 0x70cfd0, previous0x7049f0). The knowledge setup routine retains the
relevant key-array fields and its record stride0x5620; its other member accesses
have changes, so this evidence is narrower than a claim that every object is
unchanged. Existing count/capacity/readability guards remain important.

All new signatures are strict and selected only for the new accepted build.
Unknown fingerprints still fail closed. Required signatures must match exactly
once; optional missing hooks still disable only the corresponding feature.
No hardcoded runtime addresses, unchecked wildcard fallback or game-memory
writes have been added beyond the existing hook mechanism.

## Validation and limits

Build with MSVC14.44, CMake4.4.4, Ninja1.13.2, Windows SDK26100 and static CRT.
Use `LIVEMAP_LOCAL_SUFFIX=-dcraft.26319703` to identify this local DLL in logs.
Keep executable fixtures private and outside the source repository.

Eleven CTest programs/checks cover existing stores/protocol helpers, mining
register decoding, exact old/new hook RVAs, unknown fingerprints, every corrupt
mandatory signature, duplicate mandatory matches and missing optional mining.
Release assertions remain enabled for the additional regression programs.

An isolated Wine11 instance with a copied backup world and PrivateNetwork=yes
served advancing game time, weather, eight bases and the persisted map routes.
It could not complete its Steam connection; Ctrl+C reached gameflow shutdown
but shutdown remained waiting, so only this disposable instance was terminated.
This is not proof of normal live-server shutdown or player interaction.

Real player movement, newly mined deposits, chest interaction and per-player
knowledge need explicit acceptance against the running server. Existing
defensive memory reads and knowledge-layout validation remain enabled.

Future game patches still require review. An upstream release or closed issue
is a review signal, not permission to disable the fingerprint guard.
